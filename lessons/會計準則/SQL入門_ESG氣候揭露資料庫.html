你手上有什麼

Excel 的「原始資料」工作表和這個資料庫是同一份東西，差別在「怎麼問它問題」。Excel 用樞紐和篩選，資料庫用一句話：SQL。

為什麼要學

Excel 彙總表只有預先算好的切法。資料庫讓你自己決定：半導體業、100 億以上、沒做情境分析的公司有哪幾家？一句話就有答案。

第 1 站

打開資料庫（10 分鐘）

已幫你做好的事：DB Browser for SQLite 3.13.1 已安裝；資料庫已複製一份到桌面（避免雲端硬碟同步時鎖檔損毀）。

SQLite 只是一種檔案格式，要用一個有畫面的軟體打開它。勾掉每一步，下次打開這頁會記得。

  1. 按 Win 鍵，輸入「DB Browser」，開啟「DB Browser for SQLite」（不是 SQLCipher 那個）。
  2. 左上角「開啟資料庫」（Open Database，Ctrl+O），選桌面的 ESG平台_氣候揭露資料庫.db。
  3. 看到四個分頁：資料庫結構（Database Structure）、瀏覽資料（Browse Data）、編輯 Pragma、執行 SQL（Execute SQL）。本課只用「瀏覽資料」和「執行 SQL」。
  4. 在「資料庫結構」確認有 公司年度、指標明細、說明 三張表，和 v_揭露、v_公司 兩個檢視（Views）。
  5. 切到「瀏覽資料」，上方表格下拉選 v_公司，隨便捲一捲。成功的話，第 1 站完成。
如果介面是英文：選單 View → Preferences → Language 可以改中文（要重開程式）。英文與中文對照本頁都會並列。

關鍵觀念：揭露率就是平均

「有揭露」只有 1 或 0，所以它的平均值就是揭露率。點下面 10 家公司切換有沒有揭露，看 AVG(有揭露) 怎麼變。

AVG(有揭露) ＝ 0.7 → 揭露率 70.0%

整份教學所有的揭露率都是這一個算式：ROUND(AVG(有揭露) * 100, 1)。

SQL 只要先會五個關鍵字（10 分鐘）

SQL 的句子像在點餐：從哪張表、挑哪些欄、篩什麼條件、怎麼分組、怎麼排序。

關鍵字白話對應 Excel
SELECT我要看哪些欄位，或要算什麼挑欄位、寫公式
FROM從哪張表選工作表
WHERE只要符合條件的列篩選
GROUP BY按某欄分組後再算樞紐分析表的「列」
ORDER BY排序，DESC 是由大到小排序

拼一句看看

用下拉選單拼出一句 SQL，右邊會即時出現句子；引擎啟動後按「執行」就有結果。你會發現十三個查詢其實都是這個骨架。

引擎未啟動時只顯示句子
常見錯誤都出在這裡：文字要用半形單引號 '上市'；欄位名稱不用引號；句尾加分號；LIKE '5 情境分析%' 的百分號代表「後面任意文字」；從 Word 貼過來的彎引號會出錯，本頁的 SQL 都是半形，直接複製。

下一站：資料的限制
第 5 站

資料的限制：揭露率怎麼判的，哪裡可能偏高

「有揭露」是用文字規則判的，不是人工逐筆閱讀。知道規則，引用數字才站得住。

  • 空白、「無」、「不適用」之類的短答案，判為沒有揭露。
  • 超過 40 字的長答案一律當作有揭露。問題在這：有些公司寫「目前尚未規劃內部碳定價，將持續關注」，字數夠長就被算成有。Q8 的結果裡看得到。
  • 所以資料庫多了「疑似否定」欄位：已判有揭露，但原文含「尚未、未規劃、未採用、並未、沒有、不適用」等字。Q13 的嚴格版就是扣掉這些。

原揭露率 vs 嚴格版（114 年度，上市＋上櫃）

嚴格版也是粗略的關鍵字比對，可能漏抓或誤抓，兩個數字當作區間看。第 8 項氣候相關目標差近 10 個百分點，引用時建議用嚴格版或註明。其他限制：資本額與產業別是 2026-10-22 的快照，兩年度共用同一分級；範疇一二三排放量填 0 的公司也算有揭露。

下一站：回到 Excel
第 6 站

把結果帶回 Excel

  1. 在 DB Browser「執行 SQL」跑出結果後，結果表格右上方有「儲存結果檢視」（Save the results view）按鈕，選「匯出成 CSV」（Export to CSV）。
  2. 在 Excel 用「資料」→「從文字/CSV」開啟，檔案原始格式選 65001: Unicode (UTF-8)，中文才不會變亂碼。直接雙擊 CSV 常會亂碼。
  3. 要做圖或簡報這樣就夠。資料庫是這一次抓取的快照，之後更新要重新產生。

在這一頁跑的結果也可以按「下載 CSV」存檔，同樣用上面的方式開。

第 8 站

速查與下一步

SQL 速查

  • COUNT(*) 數列數；AVG(x) 平均；SUM(x) 加總；ROUND(x, 1) 四捨五入。
  • WHERE a = 1 AND b = '上市'；OR；IN ('5','6','7')；LIKE '開頭%'。
  • GROUP BY 欄 搭配 HAVING COUNT(*) >= 10 去掉小樣本。
  • ORDER BY 欄 DESC；LIMIT 10。
  • CASE WHEN 條件 THEN 值 END：像 IF，做交叉表用。
  • 只有 INSERT、UPDATE、DELETE、DROP 會改資料。本課全部是 SELECT，怎麼玩都安全。

之後想問新問題

  • 把問題用中文寫出來，附第 2 站的欄位表，例如「114 年上櫃、食品工業、範疇一確信是有限確信的公司有哪些」，請 Claude 寫 SQL。
  • 練習順序：先把 Q3 到 Q5 改條件玩一遍（換年度、市場、指標），再試 Q7 找公司，最後看 CASE WHEN。
  • 建議：每學會一題就把你自己改過的版本貼到筆記，一週後回來重跑一次。
