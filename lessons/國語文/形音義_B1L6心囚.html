形音義好棒棒｜心囚 61 組

俠狹挾陝、錮涸箇痼、僚繚潦燎撩療、憔樵瞧礁、悴淬萃瘁粹猝、潦的三種念法……會的快速跳過，不會的自動多練。

1. 要練哪一段？（點一格）

從第 組到第 組

2. 聰明複習（建議用這個）

一回大約 3 分鐘。上次答錯的先出，再出還沒做過的；第一次就答對的直接算「熟了」，不再浪費時間。答錯的題，隔幾題會再出一次，之後還要再答對一次才算熟。
不確定的題目，作答前先勾「這題我是用猜的」：猜對也不算熟，會收進錯題本下次再考。

想自己選題型、題數，或改成用手寫

練哪一種題型？

看詞選字怎麼作答？（聰明複習也會照這個）

用手寫：不給選項，在格子裡用手指或滑鼠把字寫出來，再翻答案對照。對不對由自己判斷，最接近考試寫字的感覺。

這次做幾題？

怎麼排最省力

  1. 一天練一段（大約 15 組），每段做聰明複習，做到進度條變滿。
  2. 隔天先回上一段做一回，再開新的一段。隔一天再想起來，記得最久。
  3. 考前一天選「全部 61 組」做驗收，再到「我的錯題」把剩下的清掉。
  4. 老是錯同一組字，去「五個訣竅」看那一家的比較表。

怎麼用這一頁

這一課的字幾乎都是「一家人」：一半長得一樣，部首不同。每一招先看例子，點有框的字會翻出答案。看完按「用這招練幾題」。

標著 講義筆記 的，是講義上手寫的提醒。

1一半一樣，看部首選字形

部首告訴你「這個字跟什麼有關」。先想詞的意思，再挑部首。
  • 俠 狹 挾 陝
  • 錮 涸 箇 痼
  • 僚 繚 潦 燎 撩 療
  • 寮 獠 遼 嘹 瞭 鐐
  • 銬 拷 烤
  • 憔 樵 瞧 礁
  • 悴 淬 萃 瘁 粹 猝
  • 枷 痂 咖
  • 陷 餡 諂
這一課是「心囚」，所以很多字跟「關起來」有關：囚、囹圄、圈都有「囗」（圍牆）；鐐、銬、鋃鐺、錮是金屬；枷、桎梏是木頭。

2同一家，但有人念不一樣音

一家人的音通常一樣。只要記「不一樣的那一個」。
家族大家都念例外（要背這個）

3破音字：先看意思，音就出來音

同一個字念不同音，是因為意思不同。這一課有四個。
字念法什麼時候例子
潦ㄌㄧㄠˊ草率、不得志字跡潦草、窮困潦倒
ㄌㄠˇ積水行潦川流
ㄌㄠˋ淹水成災（通「澇」）旱潦
瞭ㄌㄧㄠˇ明白、清楚明瞭、瞭如指掌
ㄌㄧㄠˋ遠看瞭望
溺ㄋㄧˋ淹、沉迷、過分沉溺、溺斃、溺愛、溺於酒色
ㄋㄧㄠˋ小便（通「尿」）隨地便溺
圈ㄐㄩㄢˋ養牲畜的地方圈欄
ㄑㄩㄢ畫圈作記號可圈可點
「瞭望」是講義上畫愛心的重點：遠看念四聲ㄌㄧㄠˋ，不是明瞭的ㄌㄧㄠˇ。講義筆記

4一字多義：把解釋放回去念念看義

不要硬背。把選項的解釋換進詞裡念一次，最通順的就是答案。

「羅」有六個意思（講義第 2 組）

  • 天羅地網 → 羅
  • 門可羅雀 → 羅
  • 綾羅綢緞 → 羅
  • 星羅棋布 → 羅
  • 包羅萬象 → 羅
  • 搜羅 → 羅

其他多義字

  • 眼花撩亂 撩　春色撩人 撩　撩起裙襬 撩　撩髮 撩
  • 溺於酒色 溺　溺斃 溺　溺愛 溺
  • 怪病纏身 纏　死纏爛打 纏　真難纏 纏
  • 淪陷 陷　陷害 陷　陷阱 陷　缺陷 陷
  • 左右不離 左右　左右為難 左右　三十左右 左右
  • 斗室生輝 斗　斗膽 斗
  • 鬱鬱寡歡 鬱鬱　鬱鬱蔥蔥 鬱鬱
最容易搞混：同一個「斗」，斗室是「小」，斗膽是「大」。

5成語先抓「比喻」那一句義

先想字面的畫面，再問「這個畫面在比喻什麼」。
  • 門可羅雀：門口可以張網抓麻雀 → 形容
  • 涸轍之鮒：乾掉的車輪痕裡的鯽魚 → 比喻
  • 星火燎原：小火星燒掉整片原野 → 比喻
  • 席不暇暖：座位還沒坐熱就要走 → 比喻
  • 煮字療飢：煮「字」來止餓 → 意思
  • 鋃鐺入獄：鐵鍊叮叮噹噹 → 意思
  • 可圈可點：文章值得畫圈、加點 → 比喻
  • 楚囚對泣：囚犯面對面哭 → 比喻
