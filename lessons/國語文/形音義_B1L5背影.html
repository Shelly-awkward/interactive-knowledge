2. 聰明複習（建議用這個）

一回大約 3 分鐘。上次答錯的先出，再出還沒做過的；第一次就答對的直接算「熟了」，不再浪費時間。答錯的題，隔幾題會再出一次，之後還要再答對一次才算熟。

看詞選字怎麼作答？（聰明複習也會照這個）

用手寫：不給選項，在格子裡用手指或滑鼠把字寫出來，再翻答案對照。對不對由自己判斷，最接近考試寫字的感覺。

這次做幾題？

怎麼排最省力

  1. 一天練一段（16 組），每段做聰明複習，做到進度條變滿。
  2. 隔天先回上一段做一回，再開新的一段。隔一天再想起來，記得最久。
  3. 考前一天選「全部 64 組」做驗收，再到「我的錯題」把剩下的清掉。
  4. 老是錯同一組字，去「五個訣竅」看那一家的比較表。

怎麼用這一頁

這一課的字幾乎都是「一家人」：右半邊一樣，部首不同。每一招先看例子，點有框的字會翻出答案。看完按「用這招練幾題」。

標著 講義筆記 的，是講義上手寫的提醒。

1右邊一樣，看部首選字形

部首告訴你「這個字跟什麼有關」。先想詞的意思，再挑部首。
  • 浦 埔 圃 鋪
  • 弦 眩 炫
  • 囑 矚
  • 迂 紆 吁 盱 竽
  • 跚 柵 珊 刪 姍
  • 攙 饞 讒
  • 榜 滂 謗 膀
  • 御 vs 禦　抵「禦」外侮、「禦」寒才有下面的「示」
  • 釣 vs 鈞　千「鈞」一髮右邊是「勻」，不是「均」

2同一家，但有人念不一樣音

一家人的音通常一樣。只要記「不一樣的那一個」。

3破音字：先看意思，音就出來音

同一個字念不同音，是因為意思不同。這一課有七個。
字念法什麼時候例子
鋪ㄆㄨ動作：攤開、布置鋪棉被、鋪設鐵路、鋪張
ㄆㄨˋ地方：商店、床位雜貨鋪、臥鋪

4一字多義：把解釋放回去念念看義

不要硬背。把選項的解釋換進詞裡念一次，最通順的就是答案。

「望」有五個意思（講義 36 組）

  • 望梅止渴、四處張望 → 望
  • 眾望所歸 → 望
  • 望車外看 → 望
  • 望子成龍 → 望
  • 坐二望一 → 望

其他多義字

  • 勾留 勾　勾銷 勾　勾結 勾　勾勒 勾
  • 屬地 屬　眷屬 屬　附屬 屬
  • 戴帽子 戴　披星戴月 戴　愛戴 戴
  • 賦歸 賦　秉賦 賦　田賦 賦
講義第 18 組「賦閒」旁邊有手寫修改：看起來是把「給與、授與」另外拉出去寫成「賦與」，「賦閒」則圈到「吟詠、寫作」。照片看不太清楚，這一個詞的字義這裡不出題，請對照自己的講義。講義筆記

5成語先抓「比喻」那一句義

先想字面的畫面，再問「這個畫面在比喻什麼」。
  • 合浦還珠：珍珠跑掉又回來 → 比喻
  • 望梅止渴：想到梅子流口水 → 比喻
  • 箭在弦上，不得不發 → 比喻
  • 披星戴月：頭上頂著星星月亮 → 形容
  • 喪家之犬：沒有家的狗 → 比喻
  • 鶼鰈情深：比翼鳥和比目魚 → 比喻
「差強人意」的「差」是「還、稍微」：大體上還能讓人勉強滿意。它是「還可以」，不是「很差」。
