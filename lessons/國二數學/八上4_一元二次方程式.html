一元二次方程式

三個小節＋章末總測驗。解一元二次方程式有三招：因式分解、配方法、公式解。三招背後都靠同一件事：「兩數相乘等於 0，其中一個一定是 0」。這一章先用零乘積機讓你看清楚為什麼等於 6 就不行，再用拼圖看配方法到底在補什麼。

🎯 學習目標

  • 認得出一元二次方程式的長相
  • 說得出為什麼一定要先整理成「＝ 0」
  • 會用因式分解解一元二次方程式

📖 觀念 1：一元二次方程式長這樣

ax² ＋ bx ＋ c ＝ 0　（a ≠ 0）

一個未知數（一元），最高次方是 2（二次）。因為有 x²，答案常常會有兩個。

💡 x² ＝ 9 的解是 3 和 −3。這是最簡單的一元二次方程式，已經看得出「兩個解」是常態。

📖 觀念 2：兩數相乘等於 0，其中一個一定是 0

這條叫零乘積性質，是整章的地基：

如果 A × B ＝ 0，那麼 A ＝ 0 或 B ＝ 0

所以只要把方程式整理成「（一坨）×（一坨）＝ 0」，就能拆成兩個一元一次方程式，各自解掉。

⚠️ 這招只對 0 有效。A × B ＝ 6 不能說 A ＝ 6 或 B ＝ 6，因為 2×3、1×6、−2×−3 都等於 6。下面的機器會讓你看到差別。

🛠️ 零乘積機

右邊等於 0 和等於 6，差在哪裡？按按看。

📖 觀念 3：因式分解解法，三個步驟

① 全部移到左邊，右邊留 0　→　② 左邊因式分解　→　③ 每個因式各自 ＝ 0，解出來
步驟式子
原式x² ＋ 5x ＝ −6
① 移項x² ＋ 5x ＋ 6 ＝ 0
② 因式分解(x ＋ 2)(x ＋ 3) ＝ 0
③ 各自 ＝ 0x ＋ 2 ＝ 0 或 x ＋ 3 ＝ 0
答案x ＝ −2 或 x ＝ −3
⚠️ 步驟 ① 最常被跳過。如果左邊是 (x＋2)(x＋3) 但右邊是 6，直接說 x＋2 ＝ 6 就錯了。一定要先讓右邊變 0。

✏️ 例題

例題 1　解 x² − 7x ＋ 12 ＝ 0

① 右邊已經是 0，直接因式分解。

② 找兩數相乘 12、相加 −7：是 −3 和 −4。(x − 3)(x − 4) ＝ 0。

③ x ＝ 3 或 x ＝ 4。

例題 2　解 x² ＝ 5x

① 先移項：x² − 5x ＝ 0。

② 提公因式：x(x − 5) ＝ 0。

③ x ＝ 0 或 x ＝ 5。（不要把兩邊同除以 x，會把 x ＝ 0 這個解弄丟）

例題 3　解 (x ＋ 1)(x − 2) ＝ 4

① 右邊不是 0，不能直接拆。先展開：x² − x − 2 ＝ 4。

② 移項：x² − x − 6 ＝ 0，因式分解：(x − 3)(x ＋ 2) ＝ 0。

③ x ＝ 3 或 x ＝ −2。

🎯 學習目標

  • 認得出完全平方式的長相
  • 說得出配方法在「補」什麼
  • 用配方法解不能因式分解的方程式

📖 觀念 1：完全平方式，長得有規律

(x ＋ m)² ＝ x² ＋ 2mx ＋ m²

中間那一項是 2m，最後那一項是 m²。反過來看：中間係數的一半再平方，就是最後那一項。

看到中間係數的一半要補的數變成
x² ＋ 6x39(x ＋ 3)²
x² − 10x−525(x − 5)²
x² ＋ 5x5/225/4(x ＋ 5/2)²

🛠️ 配方法拼圖

x² 是一個正方形，bx 是兩條長方形貼在旁邊，右下角缺一塊。拉 b 看缺口大小，再按「補上」看它變成一個完整的正方形。

📖 觀念 2：配方法解方程式

當左邊因式分解不出來，就把它補成完全平方，再開根號：

步驟式子做了什麼
原式x² ＋ 6x ＋ 2 ＝ 02 不能拆成兩數相加 6、相乘 2
①x² ＋ 6x ＝ −2常數移到右邊
②x² ＋ 6x ＋ 9 ＝ −2 ＋ 9兩邊同加 (6/2)² ＝ 9
③(x ＋ 3)² ＝ 7左邊變完全平方
④x ＋ 3 ＝ ±√7開根號，正負都要
答案x ＝ −3 ± √7
⚠️ 步驟 ② 兩邊都要加，這是第 4 章學過的等量公理。只加左邊天平就歪了。
💡 如果 x² 前面有係數（例如 2x²），先整條除以那個係數，再開始配方。

✏️ 例題

例題 1　把 x² ＋ 8x 配成完全平方

① 中間係數 8 的一半是 4。

② 4 的平方是 16，補上：x² ＋ 8x ＋ 16。

③ ＝ (x ＋ 4)²。

例題 2　用配方法解 x² − 4x − 1 ＝ 0

① 常數移右邊：x² − 4x ＝ 1。

② 補 (−4/2)² ＝ 4：x² − 4x ＋ 4 ＝ 5，即 (x − 2)² ＝ 5。

③ x − 2 ＝ ±√5，x ＝ 2 ± √5。

例題 3　解 (x ＋ 1)² ＝ 16

① 已經是完全平方，直接開根號。

② x ＋ 1 ＝ ±4。

③ x ＝ 3 或 x ＝ −5。（兩個都要，很多人只寫 3）

🎯 學習目標

  • 會用公式解直接算答案
  • 用判別式判斷有幾個解
  • 把應用題列成一元二次方程式，解完會檢查合理性

📖 觀念 1：公式解，就是配方法做一次做到底

對 ax² ＋ bx ＋ c ＝ 0 做一次配方法，會得到一條萬用公式：

x ＝ −b ± √(b² − 4ac)2a

把 a、b、c 代進去就好，任何一元二次方程式都能解。缺點是計算量大，所以能因式分解就先因式分解。

⚠️ 代入時 b 和 c 的負號要一起帶進去。x² − 3x − 4 ＝ 0 的 b 是 −3、c 是 −4，不是 3 和 4。

📖 觀念 2：根號裡面那一坨，決定有幾個解

公式裡的 b² − 4ac 叫判別式，常寫成 D。它在根號裡面，所以：

D ＝ b² − 4ac根號解的個數
D ＞ 0開得出兩個不同的數兩個不相等的實數解
D ＝ 0√0 ＝ 0，± 沒差一個解（兩個相等的解）
D ＜ 0負數不能開根號沒有實數解
💡 題目問「有幾個解」不用真的解出來，算 D 就好。

📖 觀念 3：應用問題

設 x → 列出二次方程式 → 解 → 檢查哪個解合理

最後一步比一元一次更重要，因為常常會解出兩個答案，其中一個不合題意（例如長度是負的、人數是小數）。

題型列式的關鍵
面積長 × 寬 ＝ 面積，長寬用 x 表示
連續整數設 x、x＋1，相乘或平方和等於題目給的數
數字問題「某數的平方比它的 3 倍多 10」→ x² ＝ 3x ＋ 10

✏️ 例題

例題 1　用公式解 x² ＋ 3x − 2 ＝ 0

① a ＝ 1、b ＝ 3、c ＝ −2。

② D ＝ 3² − 4×1×(−2) ＝ 9 ＋ 8 ＝ 17。

③ x ＝ (−3 ± √17) / 2。

例題 2　x² − 6x ＋ 9 ＝ 0 有幾個解？

① D ＝ (−6)² − 4×1×9 ＝ 36 − 36 ＝ 0。

② D ＝ 0，只有一個解。

③ 確認：(x − 3)² ＝ 0，x ＝ 3。

例題 3　長方形的長比寬多 3 公分，面積 40 平方公分，求寬

① 設寬 x，長 x ＋ 3：x(x ＋ 3) ＝ 40。

② x² ＋ 3x − 40 ＝ 0，(x ＋ 8)(x − 5) ＝ 0，x ＝ −8 或 5。

③ 寬不能是負的，捨去 −8。寬是 5 公分。
