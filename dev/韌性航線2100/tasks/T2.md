# T2 地圖與廠址畫面

你負責開局的兩個畫面元件：公司卡選擇、虛構地圖與選廠址。

## 目標

實作 `SPEC.md` 第 6 節的兩個函式，覆蓋 `STUBS` 的陽春版：

- `CG.ui.renderCompanyPicker(el, {selectedId}, onPick)`
  - 5 張公司卡（`GAME_DATA.companies`）：名稱、產業、規模、`caseRef`（有的話加「懶人包案例」標籤）、SASB 主題標籤（`sasb`）、線索（`clues`，`clueSrc` 標的那幾條要加 `srcTag`）、每回合預算與分析點（加「遊戲假設」標籤）。
  - 卡片下方顯示一次 `text.sasbNote`。
  - 光看卡片，玩家要能猜到這家公司會遇到什麼風險，所以線索要醒目。
  - 整張卡可點（`<button>`），點了呼叫 `onPick(id)`；`selectedId` 那張有選取樣式與 `aria-pressed="true"`。
- `CG.ui.renderMap(el, {companyId, selectedTileId}, onPick)`
  - 標題用 `map.name`，說明用 `map.note`。
  - 6×6 格（`CG.core.tiles()`），每格是 `<button data-tile="r2c0">`，用 CSS grid；375px 時整張圖要在寬度內，每格至少 44×44。
  - 每格顯示地形簡稱與底色（六種地形用不同的淡色），再加風險徽章：`hazardBadges` 的字（淹／潮／熱／坡），係數 ≥1.2 標「高」、≥0.8「中」、≥0.4「低」，更低不標。徽章要看得懂高低（例如顏色深淺），不能只靠顏色。
  - 有圖例說明四個徽章字和高中低。
  - 河口低地格加一個小記號，旁邊說明 `map.caseHint.text`。
  - 選定的格子（`selectedTileId`）有明顯外框；下方資訊面板顯示：地形名、`pros`、`cons`、四種風險係數的高中低。**不要直接列出「這家公司會遇到哪些風險」**，那是第 1 步要玩家自己判斷的。
  - Z 教育（`siteSensitive:false`）時，資訊面板加一句「以線上課程為主，據點影響很小」。
  - 點格子呼叫 `onPick(tileId)`；鍵盤 Enter／空白鍵也能選；每格有 `aria-label`（例如「第 3 列第 1 欄，河口低地，淹水高」）。方向鍵移動焦點是加分項，不強制。

## 輸入

- `dev/韌性航線2100/SPEC.md`（第 2、6 節）
- 遊戲檔的 `DATA`（`companies`、`terrains`、`map`、`hazardBadges`、`text`）、`STYLE-CORE`、`CORE`、`STUBS`

## 輸出

只改遊戲檔的 `MAP` 與 `STYLE-MAP` 區塊。

