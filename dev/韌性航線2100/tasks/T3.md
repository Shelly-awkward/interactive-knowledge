# T3 事件與顧問建議系統

你負責顧問「阿嵐」說的話、每一步的對錯回饋，以及資料庫卡、參數卡、預估、事件卡這四種卡片。

## 目標

實作 `SPEC.md` 第 6 節「T3」的七個函式，覆蓋 `STUBS` 的陽春版：

- `advisorTurnStart(game)`：取 `advisor.turnStart[公司][回合]`，把 `{site}` 換成廠址地形名，回傳 `{text, src}`。
- `feedbackLines(stepNo, check, game)`：依 `CG.core.check.stepN` 的結果，套 `advisor.feedback` 的句子，回傳 `[{text, src?}]`。
  - `{list}` 用中文名稱（風險名、資料類別名）以「、」串起來；`{n}` 是數字；`{cost}` 用 `CG.core.fmtYi`；`{depth}` 是深度名稱。
  - 第 1 步：noneCase 且 ok → `step1NoneOk`；ok → `step1Ok`；有 missing → `step1Missing`；有 extra → `step1Extra`（兩句可同時出現）。
  - 第 2 步：`noneOk`、`noneWrong`、`missing`、`irrelevant`（帶 `{n}` ＝ apPenalty）、ok；`check.showDbLimits` 為 true 時**一定**再加一句 `dbLimits`。
  - 第 3 步：依 `reason`（ok／sameSide／reference／notNeeded）。
  - 第 4 步：ok → `reasonKey` 那句；`diff > 0` → `step4Over`；`diff < 0` → `step4Under`，再補一句 `reasonKey` 說明正解。
  - 第 5 步：`step5Score`；第 6 步：`step6Ok` 或 `step6Missing`。
- `renderAdvisor(el, {text, src})`：在 `el` 後面加一個對話框，有顧問名字 `advisor.name`、頭銜，文字，`src` 有值時加 `srcTag`。頭像用 CSS 或內嵌 SVG 畫一個簡單的原創圖形，不要用任何現有角色。
- `renderDatabaseCards(el, {selected, onToggle})`：五張資料類別卡（`dataFamilies`），每張是 `<button aria-pressed>`：名稱、適用時機 `when`、參數例子、資料庫清單與各自的 `note`；卡片下方顯示 `siteChangeNote`。點了呼叫 `onToggle(id)`。
- `renderParameterCards(el, {families, scenarios, turnIndex})`：列出 `parameters` 中 `family` 在 `families` 裡的參數；每個參數顯示 `base`（加 `baseSrc` 標籤），再列每個選到的情境在這回合的值（`values[情境][turnIndex]`，加 `src` 標籤；沒有值就寫「此情境不適用這個參數」）。
- `renderForecast(el, {game, turnIndex, routeIds, extraMeasureIds})`：每條路線一塊。
  - 用 `CG.core.project` 算本回合（措施＝之前買的＋`extraMeasureIds`），用 `CG.core.assess` 算到長期。
  - 每個風險的精細度照 `CG.core.forecastLevel(game.turns[turnIndex], risk)`：`hidden` 不顯示（只在最後寫「還有 N 項事件沒有辨識，看不到」，不能說出是哪些）；`noData` 寫「缺資料，估不出來」；`qualitative` 只寫方向（產能會下降／現金流會變差）；`simplified` 用 `CG.core.band` 的輕微／中等／嚴重；`full` 寫數字（產能 −x 個百分點、每年 −x 億元）。
  - 兩個儀表（本回合產能、長期年現金流）也照「這回合的深度」決定精細度；`full` 才寫數字。
  - 路線名稱用「若世界走『高排放路線』」這種說法，**不能透露實際路線**。
- `renderEventCards(el, events, {companyId, turnIndex})`：每個事件一張卡，外層 `data-kind`。
  - 顏色：實體 `--phys`、轉型 `--trans`、機會 `--opp`；同時有文字標籤「實體風險／轉型風險／機會」。
  - 內容：標題、`text`、影響（產能 −x 個百分點，或每年 ±x 億元）。`raw ≠ value` 時寫「調適前 … → 調適後 …」，並列出 `mitigatedBy` 的措施名稱。
  - 碳費卡另外寫算式：應繳排放量（`extra.emissions` 萬噸，減碳後 `extra.emissionsAfter`）× 費率（NT$/噸；有 `usd` 時寫成「US$303 × 匯率 30」）＝ 金額，並加 `extra.price.src`、`extra.price.fxSrc`、`extra.emissionsSrc` 的標籤。
  - `missed` 的機會卡寫「錯過：要先有 ○○」（`extra.requires` 的措施名，用「或」連）。
  - `extra.longNote` 有值時加在卡片上，並加它的 `src` 標籤。
  - 事件的 `src` 為 `assumed` 時，影響數字旁加「遊戲假設」。
  - 空陣列時顯示一張中性的卡，文字是 `GAME_DATA.noEventText`。
